# Cabañas de ejemplo (Consola Python bpy)

Cinco cabañas distintas, cada una en un archivo `.py` independiente.
Para usarlas, abre **Consola Python (bpy)** en la app, copia el contenido de un archivo
y pulsa **Ejecutar en Consola** o **Ejecutar y Ver en 3D**. Cada script borra la escena antes de construir.

| Archivo | Descripción |
|---|---|
| `cabana_1_troncos_clasica.py` | Cabaña de troncos de una planta, con interior, puerta abierta y porche. |
| `cabana_2_posada_dos_plantas.py` | Posada de dos plantas con escalera interior, balcón y tejado de pizarra. |
| `cabana_3_pescador_pilotes.py` | Cabaña de pescador sobre pilotes, con muelle, barca y tejado de paja. |
| `cabana_4_torre_de_vigia.py` | Casa de piedra y madera con torre de vigía de piedra y tejado piramidal. |
| `cabana_5_redonda.py` | Cabaña redonda de piedra y madera con tejado cónico y hogar central. |

Todas las puertas están abiertas para poder entrar. El visor de la app no tiene modo de caminar:
para ver el interior hay que orbitar, hacer zoom o mirar por la puerta.
